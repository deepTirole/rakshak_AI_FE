# 🪖 Rakshak AI

**Status: DECLASSIFIED // Clearance: LEVEL 1**

Rakshak AI is a stateless, AI-powered readiness engine built for Indian Armed Forces aspirants. Driven by an uncompromising "Ustad" (Drill Sergeant) AI persona, it generates synchronized, dual-pillar mission plans balancing strict physical conditioning with academic syllabus tracking.

## 🛠️ Tech Stack
* **Frontend:** Angular 21, Tailwind CSS (Tactical "Command Center" UI), RxJS
* **Backend:** Spring Boot 3.x, Java 21, Spring Web
* **AI Integration:** Spring AI with Google Gemini API (`gemini-2.5-flash`)

## ⚙️ Local Setup

### Prerequisites
* Java 21 & Maven
* Node.js (v18+) & npm
* A free [Google Gemini API Key](https://aistudio.google.com/)
